# **App Name**: GeoMeasure

## Core Features:

- User Authentication & Profiles: Secure user registration, login, and a profile page to manage account details and view measurement history.
- GPS Area Mapping: Utilize mobile device GPS to record a series of coordinates by walking or driving a perimeter, dynamically drawing the boundary on a map interface.
- Area Calculation & Conversion: Automatically calculate the enclosed area of a mapped region upon completing a loop, displaying results in square meters, square feet, acres, and hectares.
- GPS Line Measurement: Measure the straight-line distance between two selected GPS points, displaying results in miles and kilometers.
- Measurement History & Management: Store and display a list of all saved area and distance measurements in the user's profile, allowing for review and selection.
- Smart Measurement Insights (AI): Leverage a generative AI tool to provide contextual information or brief suggestions relevant to the measured land area, such as general crop suitability based on region or size.

## Style Guidelines:

- A high-contrast three-color palette. Primary: Jet Black (#000000) for text and core structural elements. Secondary: Vibrant Cobalt Blue (#2D5BFF) for active paths, action buttons, and GPS markers. Accent/Other: Crisp Studio White (#FFFFFF) for the background to ensure map clarity.
- A single clean sans-serif font: 'Inter'. This choice ensures modern readability and conveys an objective, precise feel suitable for numerical data.
- Simple, clean, geometric line icons for GPS, maps, rulers, save, and user profiles to maintain a technical and modern aesthetic.
- A mobile-first design featuring prominent map displays. Measurement history is organized in a card-based layout for easy navigation.
- Subtle and functional animations, such as smooth transitions for map panning and a pulse effect on the active GPS recording point.
